Лабораторная работа №4. Закрепление навыков работы с Git, Markdown, терминалом и проектной структурой

ФИО: Изингер Алексей

Группа: Группа ИСП-242

Описание деятельности

На текущей паре по ИСРПО мы изучаем основы работы с ветками и коммитами в системе контроля версий Git, практикуемся в оформлении технической документации с помощью языка разметки Markdown, а также учимся взаимодействовать с операционной системой через консольный терминал Bash/PowerShell и создавать базовые проекты на платформе .NET.

Список изучаемых технологий:

  • Система контроля версий Git и сервис GitHub
  • Язык разметки документов Markdown
  • Командная строка и базовые утилиты терминала
  • Платформа .NET Core и язык программирования C#
  • Структурирование проектных каталогов
